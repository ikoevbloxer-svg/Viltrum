# Viltrum — Силы Неуязвимого (NeoForge 1.21.1)

modid: `viltrum` (внутреннее имя мода, менять не нужно), пакет `com.viltrum`.

## Сборка
1. Положи в корень проекта `gradlew`, `gradlew.bat` и `gradle/wrapper/gradle-wrapper.jar` из любого своего мода на NeoForge 1.21.1
   (или распакуй сюда MDK и перенеси папку `src/` и `gradle.properties`).
2. `./gradlew build` -> `build/libs/viltrum-1.0.0.jar`; для теста `./gradlew runClient`.
3. Если Gradle не находит `neo_version=21.1.172`, поставь ту версию NeoForge 21.1.x, что у тебя в других модах.

## Как получить силу
- `/viltrum become` (нужны права оператора) или скрафти/возьми из креатива «Сыворотку вилтрумита» и нажми ПКМ.
- `/viltrum level <1-10>` — задать уровень.

## Управление (меняется в настройках управления, категория «Силы вилтрумита»)
| Клавиша | Действие |
|---|---|
| G | Меню силы: ползунок мощности (сдерживание), лимит скорости полёта, пресеты, переключатели |
| V или двойной пробел | Включить/выключить полёт |
| W/A/S/D + взгляд | Полёт туда, куда смотришь; Пробел вверх, Shift вниз |
| Ctrl (спринт) | Форсаж, на высоком уровне — звуковой барьер, ударные кольца, конус пара, разрушение блоков на пути |
| X (держать) | Заряд мощного удара, отпустить — рывок и удар, ударная волна, кратер |
| Z (держать) | Шквал ударов (звук barrage.mp3); во время хвата — избиение схваченного |
| C | **Хват за шею** (ур. 10): схватить цель перед собой / отпустить |
| X (держать) при хвате | Бросок схваченного, при ударе о стену/землю он получает урон, остаются кратеры |
| N | Чувства вилтрумита (ур. 5): ночное зрение + подсветка существ в 40 блоках |
| H | Громовой хлопок (ур. 15): ударная волна вокруг, откидывает всех |
| R | **Ярость** (ур. 12): мощность растёт до 165%, длится ~20+ с, потом перезарядка |
| J | **Топот** (ур. 18): удар ногой, в радиусе вокруг мгновенно гибнут все враждебные мобы |
| K | При хвате: **убить** схваченного |

Ползунок «Мощность» масштабирует урон, отбрасывание, разрушения и скорость добычи руками. На 10% удар почти безопасный, на 100% — кратеры.

## Хват за шею (уровень 10+)
Схваченный висит перед тобой на вытянутых руках и **сам по себе урона не получает**: ты выбираешь, что делать.
C отпустить, K убить, X бросить, Z избить серией, удары по тебе спереди и стрелы попадают в него (живой щит), при полёте и столкновении со скалой он принимает основной удар (ты почти не страдаешь),
X бросает его, а при ударе о препятствие он получает урон и оставляет кратер. Уровень силы теперь до 50.

## Первый вход
При первом входе игрока в мир с шансом 30% он сразу становится вилтрумитом (шанс в конфиге `firstJoinViltrumiteChance`).
Игроки, которые уже заходили до обновления, тоже бросят этот кубик один раз при следующем входе.

## Что внутри
- Прогрессия 1–50 уровней (опыт за бой, убийства и полёт), регенерация, сопротивление урону.
- Полёт с инерцией, наклоном тела, креном в поворотах, позой «Супермена» (миксин в HumanoidModel), FOV, тряска камеры, линии скорости, виньетка, вспышка при звуковом барьере, потоки ветра, дорожка пара, пыль от земли.
- Звуки: твои mp3 (удары, шквал, кость, лазер, левел-ап) + сгенерированные (ветер, взлёт, форсаж, звуковой хлопок, посадка, удар о землю, накопление силы, костюм).
- Мобы: Вилтрумит (летит на цель, мощные удары), Реанимен (регенерация), Флаксан (лазерная винтовка). Яйца призыва и естественный спавн.
- Костюмы Неуязвимого и Омни-Мэна (полные комплекты дают бонусы), бластер флаксанов.
- Конфиг `config/viltrum-common.toml`: разрушения (радиус кратеров до 20, бюджет блоков), лимиты, множитель опыта. Ключи переименованы, поэтому новые значения по умолчанию применятся и со старым файлом конфига.

## Пересборка ассетов
